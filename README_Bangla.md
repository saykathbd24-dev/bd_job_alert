# BD Govt Job Telegram Bot v4 — মোবাইল গাইড

## আগের সংস্করণের সমস্যার সমাধান

আগের v3-এ প্রতিটি Alljobs বিস্তারিত পেজে `page.goto()` চলত। ফলে GitHub-এ বারবার `Timeout 9000ms exceeded` দেখা যাচ্ছিল। v4-এ **কোনো বিস্তারিত পেজ খোলা হয় না**। Alljobs-এর সরকারি চাকরি/পরীক্ষার বিজ্ঞপ্তির তালিকার দৃশ্যমান কার্ড ও অফিসিয়াল সাইটের JSON ডেটা দেখে তথ্য যাচাইয়ের চেষ্টা করা হয়। সর্বোচ্চ ৫ মিনিট GitHub Run চলবে।

**সীমাবদ্ধতা:** Alljobs-এর তালিকা বা JSON-এ প্রতিষ্ঠান, পদ ও আবেদনের শেষ তারিখ না থাকলে সতর্কতা পাঠাবে না। সেই ক্ষেত্রে Run লাল (Failure) দেখাবে। সাইটের বর্তমান কাঠামো অনুযায়ী আরও পরিবর্তন প্রয়োজন হতে পারে। বাস্তবে Telegram-এ বিজ্ঞপ্তি পৌঁছানো এখনও পরীক্ষা করা হয়নি। Teletalk VAS SSL Error থাকলে সেটা লগে Warning হবে। BPSC-এর সম্পূর্ণ কভারেজ এই সংস্করণে নেই।

## মোবাইলে আপডেট করো

1. ZIP Extract করো। `bot.py`, `requirements.txt` ও `.github/workflows/alerts.yml` ফাইল তিনটি খুঁজে বের করো।
2. GitHub-এ `saykathbd24-dev/bd_job_alert` Repository খোলো।
3. **শুধু বিদ্যমান ফাইলগুলোর কোড বদলাও**: `bot.py`, `requirements.txt`, `.github/workflows/alerts.yml`। একই নামে দুটি ফাইল তৈরি কোরো না।
4. আগের `state.json` মুছবে বা Replace করবে না। এটি পুরোনো নোটিফিকেশনের হিসাব রাখে।
5. `BOT_TOKEN` এবং `CHAT_ID` GitHub Secrets-এ যেমন আছে, তেমনই থাকবে। কাউকে পাঠাবে না।
6. **Actions > BD Government Job Telegram Alerts > Run workflow** চাপো।
7. `check > Check official listing data and send Telegram alerts` খুলে লগ দেখো।

## কী দেখে বুঝবে?

- `LIST ... links=... valid_cards=... valid_json=...`: তালিকা থেকে কতটি সম্ভাব্য লিংক ও যাচাইযোগ্য বিজ্ঞপ্তি পাওয়া গেছে।
- `SUMMARY ... verified=...`: মোট কতটি যাচাইযোগ্য চলমান বিজ্ঞপ্তি।
- `SUCCESS verified_groups=... telegram_sent=...`: সফলভাবে পরীক্ষা সম্পন্ন এবং কতটি Telegram মেসেজ পাঠানো হয়েছে।
- `NO VERIFIED JOBS`: তালিকা থেকে প্রয়োজনীয় তথ্য পাওয়া যায়নি; এটি **লাল Error**, চুপচাপ সাফল্য নয়। লগের `first card text=...` লাইন স্ক্রিনশট দিলে পার্সার ঠিক করা সম্ভব।

## বিজ্ঞপ্তি কবে পাঠাবে?

প্রতিষ্ঠান, পদ ও মেয়াদ যাচাই করা গেলে নতুন বিজ্ঞপ্তি পাঠাবে। আবেদনের শুরু, অফিসিয়াল আবেদন/সার্কুলার লিংক না পাওয়া গেলে **'যাচাই করা যায়নি'** স্পষ্টভাবে লিখবে; অনুমান করবে না। মেয়াদ শেষ হলে বাদ দেবে। শেষের ৩, ১ বা ০ দিন আগে একবার করে স্মরণ করাবে।
